# 프랑스어 끝자음 묵음

## Core Idea

프랑스어에서는 단어 끝의 자음이 보통 발음되지 않는다.

## Form

- 특히 `-s`, `-t`, `-d`, `-p`, `-g`, `-x`, `-z` 같은 끝자음이 묵음인 경우가 많다
- 문맥에 따라 liaison이 일어나면 다음 단어와 이어서 발음될 수 있다

## When To Use

- 기본 발음 규칙을 익힐 때
- 철자와 실제 발음이 다른 프랑스어 단어를 읽을 때

## Examples

- `les` → 보통 끝의 `s`를 발음하지 않는다
- `grand` → 보통 끝의 `d`를 발음하지 않는다
- `beaucoup` → 보통 끝의 `p`를 발음하지 않는다

## Common Mistakes

- 모든 끝자음이 항상 묵음이라고 생각하지 않는다
- liaison이나 예외 발음을 무시하지 않는다

## Related

- liaison
- silent letters
- final consonants
