# 정관사 `le`

## Core Idea

`le`는 프랑스어에서 영어의 `the`에 해당하는 남성 단수 정관사이다.

## Form

- `le` + 남성 단수 명사
- 모음이나 묵음 `h` 앞에서는 `l'`로 축약된다

## When To Use

- 특정한 남성 단수 명사를 지칭할 때 사용한다
- 이미 화자와 청자가 무엇을 말하는지 알고 있는 대상을 가리킬 때 사용한다

## Examples

- `le livre` = the book
- `le problème` = the problem
- `l'homme` = the man

## Common Mistakes

- `le`를 모든 명사 앞에 그대로 쓰지 않는다
- 여성 단수 명사에는 `la`, 복수에는 `les`를 쓴다

## Related

- `la`
- `les`
- `l'`
