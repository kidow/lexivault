# 정관사 `la`, `les`

## Core Idea

`la`는 프랑스어에서 영어의 `the`에 해당하는 여성 단수 정관사이고, `les`는 남성/여성 공통 복수 정관사이다.

## Form

- `la` + 여성 단수 명사
- `les` + 남성 복수 명사 또는 여성 복수 명사
- 모음이나 묵음 `h` 앞에서는 `la`도 `l'`로 축약된다

## When To Use

- 특정한 여성 단수 명사를 지칭할 때 `la`를 쓴다
- 특정한 복수 명사를 지칭할 때 `les`를 쓴다

## Examples

- `la table` = the table
- `la femme` = the woman
- `les livres` = the books
- `les femmes` = the women

## Common Mistakes

- `la`를 남성 단수 명사 앞에 쓰지 않는다
- `les`를 단수 명사 앞에 쓰지 않는다
- `les`는 성별에 따라 나뉘지 않는 복수 정관사이다

## Related

- `le`
- `l'`
- definite article
